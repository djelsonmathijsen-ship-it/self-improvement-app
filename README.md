# Caletivity

Caletivity is a clean self-improvement mobile app concept built with Expo and React Native for iPhone.

## Features

- Daily habit tracking with streaks
- Motivational quote generator
- Mood check-in and journal reflections
- Weekly progress overview
- Mini focus planner for priorities
- Reminder cards for routines and goals
- Clean, premium dashboard design

## Run locally

```bash
npm install
npm start
```

Then press:
- i for iOS Simulator

## App structure

- `App.tsx` – app logic and UI
- `app.json` – Expo configuration for iPhone-focused app

## Notes

This is a polished product prototype meant for app-store style exploration and iteration. It stores local state in AsyncStorage and is ready to expand into a full production app with backend sync, onboarding, notifications, and subscription features.
